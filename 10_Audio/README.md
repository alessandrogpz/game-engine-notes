# Audio

A smaller domain than rendering, but a real-time system with harder latency constraints and no
tolerance for a dropped buffer.

> [!NOTE]
> **No notes yet.** This domain is at the roadmap stage. The plan — subjects, resources, and
> the order to take them in — is in [00_Roadmap.md](00_Roadmap.md).

---

## Planned subjects

| Subject | Covers |
| :--- | :--- |
| `01_Digital_Audio_Foundations` | PCM, Nyquist, the audio callback, and the no-allocation rule |
| `02_Mixing_and_Playback` | Summing, gain staging, resampling, voice management, streaming |
| `03_Spatial_Audio` | Panning, attenuation, Doppler, HRTF, occlusion and reverb zones |
| `04_DSP_Effects` | Biquad filters, delay, reverb, compression, convolution |
| `05_Engine_Integration` | Event-driven design, middleware concepts, adaptive music |

Subjects gain `Concepts/`, `Exercises/` and `Assets/` folders as work begins.
